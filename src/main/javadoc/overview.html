The official Java library for the TeachMeHIPAA Developer API: enroll your people in HIPAA training and track their compliance from your own systems.

Status: pre-release. The Developer API isn't generally available yet, and the library isn't on Maven Central. Until it is, build it from source, as the README shows.

Start with {@link com.teachmehipaa.TeachMeHipaaClient}: build one client with {@link com.teachmehipaa.TeachMeHipaaClient#builder()}, share it, and reach the API's resources through its services, such as {@code client.learners()}. Webhook Deliveries are verified with {@link com.teachmehipaa.Webhook}, which needs no client.

{@code
TeachMeHipaaClient client =
    TeachMeHipaaClient.builder()
        .clientId(System.getenv("TMH_CLIENT_ID"))
        .clientSecret(System.getenv("TMH_CLIENT_SECRET"))
        .environment(Environment.SANDBOX)
        .build();

Learner learner = client.learners().retrieve("sub_01JD8Z4N3QX5V7W9Y2B4C6D8EG");
}

Every method that sends a request has an {@code …Async} sibling, such as {@code retrieveAsync}, that returns a {@link java.util.concurrent.CompletableFuture} of the same type without blocking the calling thread.

Packages

  • {@code com.teachmehipaa}: the client, its options, and webhook verification.
  • {@code com.teachmehipaa.service}: one service per resource, reached from the client.
  • {@code com.teachmehipaa.param}: the parameters each method takes, built with {@code builder()}.
  • {@code com.teachmehipaa.model}: what the API returns, Events included.
  • {@code com.teachmehipaa.exception}: the unchecked exceptions a call can throw.
  • {@code com.teachmehipaa.core}: pagination, Operations' results, downloads, and the seams for your own HTTP transport and token provider.

Documentation. The API reference, with Java samples for every operation, and the guides live at docs.teachmehipaa.com/api.
